# 🔥 Deep Learning with PyTorch

A collection of practical deep learning projects built using **PyTorch**, covering fundamental and advanced concepts such as neural network design, model training, optimization, computer vision pipelines, and evaluation techniques.  
This repository serves as a learning hub and hands-on portfolio for experiments, research, and real-world model implementations.

---

## 🚀 Project Goals

- Strengthen and document deep learning knowledge.  
- Build and train neural networks from scratch using **PyTorch**.  
- Explore optimization strategies, training loops, and best practices.  
- Create a solid foundation for future projects in **Computer Vision**, **NLP**, and **Custom Architectures**.  

---

## 📘 Topics Covered

This repository includes:

### ✔ Fundamentals
- Perceptron  
- MLP (Multilayer Perceptron)  
- Activation functions  
- Forward and backward pass  
- Loss functions  

### ✔ Training & Optimization  
- Gradient descent & variants  
- PyTorch optimizers  
- Regularization (L2, dropout)  
- Learning rate scheduling  
- Weight initialization  

### ✔ Computer Vision  
- Image classification  
- Convolutional Neural Networks (CNNs)  
- Data augmentation  
- Transfer learning  

### ✔ Evaluation & Metrics  
- Accuracy, precision, recall, F1 score  
- Loss and accuracy curves  
- Confusion matrices    

### ✔ Good Practices  
- Experiment tracking and reproducibility  
- Seed control  
- Model saving & loading  
- Modular training pipelines
